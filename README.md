# Сайт «ШарДекор» — новый сайт-витрина

Перенос старого сайта (Joomla 3 + JoomShopping, 2012 года) на современную
статическую площадку. Каталог собран парсером со старого сайта — перенесены
все товары, разделы, фотографии, цены и тексты.

## Что внутри

```
shardekor/
  scraper/            парсер старого сайта (Python)
    scrape.py         обход старого сайта, товары, фото
    menu.py           боковое меню разделов -> out/menu.json
    tree.py           полное дерево разделов -> out/catalog.json, out/tree.json
    optimize.py       WebP-версии фотографий
    sections.json     порядок и группировка верхних разделов (правится руками)
    report.py         читаемый отчёт по дереву разделов
    out/
      catalog.json    собранный каталог
      img/            исходные фотографии
      img_opt/        WebP-версии, их отдаёт сайт
      cache/          кэш HTML-страниц (чтобы не качать повторно)
  site/               сам сайт (Next.js + Tailwind, статическая сборка)
    app/              страницы
    components/       элементы интерфейса
    lib/              каталог и настройки сайта
    scripts/          сборка данных и генерация редиректов
    deploy/           готовые конфиги для nginx и Apache
```

## Как это работает

1. `scraper/scrape.py` обходит старый сайт и собирает `out/catalog.json`
   и `out/img/*`.
2. `scraper/menu.py` восстанавливает боковое меню разделов в `out/menu.json`.
3. `scraper/tree.py` восстанавливает **полное дерево разделов** (старое меню
   показывало только 27 верхних пунктов, реально разделов ~190) и записывает
   его обратно в `out/catalog.json`.
4. `scraper/optimize.py` делает WebP-версии фотографий и переписывает ссылки.
5. `npm run build` в папке `site` копирует данные из `scraper/out`,
   генерирует статические HTML-страницы в папку `site/out`
   и создаёт 301-редиректы в `site/deploy`.
6. Папку `site/out` заливают на хостинг как обычные статические файлы.
   PHP, база данных и панель управления не нужны.

## Как пересобрать каталог

Порядок важен — каждый шаг опирается на результат предыдущего:

```bash
cd scraper
python scrape.py     # повторный запуск использует кэш, поэтому быстро
python menu.py       # out/menu.json — оригинальное меню со старого сайта
python tree.py       # out/tree.json + дерево разделов в out/catalog.json
python optimize.py   # WebP-версии фотографий
cd ../site
npm run build        # синхронизация данных, сборка, редиректы
```

**Группировка верхнего уровня** задаётся файлом `scraper/sections.json`:
список разделов, порядок которых совпадает с порядком на странице `/catalog/`,
и какие корневые категории в каждый раздел входят. Категории, не названные
там, показываются отдельными пунктами. Там же лежит раздел «Прочее» —
категории-сироты, на которые на старом сайте не ведёт ни одна родительская
страница.

## Как вносить правки

- **Телефон, почта, адреса, соцсети** → `site/lib/site.ts`
- **Цвета и шрифты** → `site/app/globals.css` (переменные `--color-rose`,
  `--color-cream` и т. д.)
- **Текст на главной** → `site/app/page.tsx`

После правок:

```bash
cd site
npm run build
```

## Залить на хостинг

Содержимое папки `site/out` — это готовый сайт. Дальше:

1. **nginx** — внутри блока `server { }` добавьте
   `include /путь/к/проекту/deploy/nginx-site.conf;`
   (если хотите переадресацию товаров по их старым номерам —
   дополнительно в блок `http { }`: `include .../deploy/nginx-product-map.conf;`)
2. **Apache** — скопируйте `deploy/.htaccess` в корень сайта.
3. Домен `шардекор.рф` переключите на новый хостинг **до** включения
   редиректов, иначе старые ссылки перестанут работать.
